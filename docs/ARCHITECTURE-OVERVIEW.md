# EdgeMeeting SDK 專案架構概述

> **給 CEO 的技術報告** | 版本 1.0 | 2026 年 1 月

---

## 一、專案概述

EdgeMeeting SDK 是一套 **端上（On-Device）即時語音轉錄 SDK**，專為 RK3588 平台優化。透過 NPU 加速執行 OpenAI Whisper 語音辨識模型，實現低延遲、高隱私的會議字幕功能。

### 核心價值

| 特性 | 描述 |
|------|------|
| **隱私優先** | 所有語音處理在本地完成，不傳送雲端 |
| **低延遲** | 音訊到字幕 < 3 秒，RTF (Real-Time Factor) < 0.3 |
| **多語言** | 支援英文、中文、日文、韓文 |
| **易整合** | 純 Kotlin API，4 個方法即可完成整合 |

## 三、模組職責

### 3.1 app（展示應用）
- **職責**：UI 展示與用戶互動
- **技術**：Jetpack Compose + Material 3
- **功能**：
  - 權限請求（麥克風）
  - 語言選擇（英/中/日/韓）
  - 狀態顯示（Idle → Ready → Listening）
  - 字幕列表呈現（區分暫時/最終結果）

### 3.2 meeting-core（合約定義）
- **職責**：定義 SDK 對外介面
- **特點**：純 Kotlin，無 Android 依賴，可在 JVM 單元測試
- **輸出**：`MeetingSession` 介面、狀態模型、資料模型

### 3.3 meeting-engine（引擎實作）
- **職責**：實作語音錄製與 ASR 推論
- **組成**：
  - **Kotlin 層**：狀態機、Flow 管理、JNI 橋接
  - **C++ 層**：音訊錄製、訊號處理、Whisper 推論

## 七、關鍵技術特點

### 7.1 效能指標

| 指標 | 數值 | 說明 |
|------|------|------|
| Real-Time Factor | < 0.3 | 10 秒音訊 < 3 秒處理 |
| 首段字幕延遲 | 2-3 秒 | 從說話開始到字幕出現 |
| 音訊路徑延遲 | < 100ms | 麥克風到 Kotlin 回調 |
| 記憶體佔用 | ~60MB | 模型 + 音訊緩衝 |
| 單段最長時間 | 20 秒 | Whisper 模型限制 |

### 7.2 技術選型

| 技術 | 選擇 | 理由 |
|------|------|------|
| 音訊庫 | Google Oboe | 低延遲、跨 Android 版本相容 |
| ASR 模型 | Whisper Base | 多語言、高準確率、開源 |
| NPU Runtime | RKNN Toolkit 2 | RK3588 原生支援、高效能 |
| FFT 庫 | FFTW3 | 業界標準、高效能 |
| UI 框架 | Jetpack Compose | 聲明式、現代化 |
| 非同步框架 | Kotlin Coroutines | 結構化併發、Flow 支援 |

### 7.3 設計模式

| 模式 | 應用場景 | 效益 |
|------|----------|------|
| Bridge Pattern | EngineBridge | 可測試性：單元測試無需 JNI |
| Strategy Pattern | AsrEngine | 擴充性：未來可支援其他 ASR |
| PImpl Idiom | WhisperAsrEngine | 隱藏 RKNN 實作細節 |
| Observer Pattern | StateFlow/SharedFlow | UI 與邏輯解耦 |

## 九、SDK 整合範例

```kotlin
// 1. 建立 Session
val session = RkMeetingSession(
    bridge = JniEngineBridge(),
    languageSetting = LanguageSetting.Fixed("zh"),
    modelProvider = { ModelAssetManager.ensureModels(context) }
)

// 2. 觀察狀態
session.state.collect { state ->
    when (state) {
        is MeetingState.Ready -> showStartButton()
        is MeetingState.Listening -> showRecordingUI()
        is MeetingState.Error -> showError(state.message)
    }
}

// 3. 收集字幕
session.transcriptFlow.collect { segments ->
    updateSubtitleList(segments)
}

// 4. 生命週期控制
session.prepare()   // 載入模型
session.start()     // 開始錄音
session.stop()      // 暫停錄音
session.release()   // 釋放資源
```

## 十一、總結

EdgeMeeting SDK 採用 **分層架構**，將純合約（meeting-core）與實作細節（meeting-engine）分離，實現高可測試性與可維護性。透過 RK3588 NPU 加速，達成端上即時語音轉錄，同時保障用戶隱私。

**核心競爭力**：
1. **隱私**：所有處理在本地完成
2. **效能**：NPU 加速，RTF < 0.3
3. **多語言**：單一模型支援 4 種語言
4. **易整合**：4 個 API 即可完成整合
